# 00. System Overview: AI Career Intelligence Agent

## Product Identity
The **AI Career Intelligence Agent** is an enterprise-grade career intelligence platform that escorts candidates through the full career progression lifecycle:
`Resume Analysis -> Job Matching -> Proactive Job Discovery -> Smart Notifications -> Tailored Application Preparation -> Application Lifecycle Tracking`.

## Core Value Proposition
1. **Explainable ATS Readiness**: Deterministic scoring and multi-faceted parsing compatibility without black-box opacity.
2. **Hybrid JD Matching**: Exact keyword matching + normalized ontology + semantic similarity + strict resume evidence verification.
3. **Continuous Autonomous Discovery (Phase 2)**: Scheduled, proactive job retrieval and ranking matching user career profiles without requiring active browser sessions.
4. **Governed Application Tailoring (Phase 2)**: Grounded resume/cover letter alignment strictly tethered to verified candidate history, gated by human approval.
5. **Standardized Tool Interoperability**: Decoupled Model Context Protocol (MCP) servers exposing isolated search, notification, document generation, and application tools.
